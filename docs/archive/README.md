# Historical records (not current execution policy)

This archive retains dated audits, proposals, verification reports, and superseded plans. Preserve original facts, branch names, and versions as **historical evidence**. Follow current [engineering governance](../engineering/README.md) and root `AGENTS.md` instead of an old audit's tool commands.

- [Repository architecture audits and migration history](repository-architecture/README.md) — dated source analyses, historical governance RFC, old migration and test topology.
- [1.0 readiness specification (2026-10-31)](release-readiness-2026-10-31.md) — a historical candidate plan, **not** the current release state.
- Current [release history](../releases/README.md) remains separate, including superseded 1.1 planning.

The append-only decision log is deliberately **not archived**; decisions keep stable IDs under [`docs/decisions/`](../decisions/README.md). Snapshot JSON files remain under `docs/a11y-snapshots/` to preserve active tooling paths.
